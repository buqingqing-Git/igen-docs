# Firmware Version Records

This page records the firmware releases of the MR1-D5-WR series. Before checking whether a feature described in this manual is supported, or before reporting an issue, verify the firmware version of the device against the records below.

The firmware version of the device can be viewed in the APP device page, on the data platform, or through the local API.

## Notes

- The models covered by this manual are MR1-D5-W, MR1-D5-WR, MR3-D5-W and MR3-D5-WR. Where a release covers only part of them, the applicable models are listed in the table.
- The manual may be updated together with a firmware release. Users should refer to the actual product purchased for the current firmware version.
