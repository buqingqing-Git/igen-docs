# Model Description

This manual covers the single-phase models **MR1-D5-W and MR1-D5-WR**, and the three-phase models **MR3-D5-W and MR3-D5-WR**. Both W and WR models support Wi-Fi, and the WR models additionally support LoRa.

<img src={require('./img/model-breakdown.png').default} alt="MR1-D5-WR model breakdown" style={{width:'300px', maxHeight:'none'}} />

| No. | Meaning | Value |
| --- | --- | --- |
| ⑴ | Product identifier | MR: Multi-function energy meter. |
| ⑵ | Number of phases | 1: Single-phase; 3: Three-phase. |
| ⑶ | Product generation | D5: 5th generation product. |
| ⑷ | Communication | W: Wi-Fi supported; R: LoRa supported. |

For detailed differences between models, see [Parameter Comparison](../parameter-comparison.md).
