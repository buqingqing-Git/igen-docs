# Product Advantages

- 1P width housing and split-core current transformers for easy installation and maintenance.
- Bidirectional metering that records consumption and generation data. Accuracy class 1.0 for active energy and class 2.0 for reactive energy.
- Millisecond-level collection of data and fault information. For upload intervals, see [Parameter Comparison](../parameter-comparison.md).
- Bluetooth built in for local network configuration. WR models support LoRa for low-power, long-distance data transmission.
- Local API available for integration into a home energy management system (HEMS).
- Compliant with the EN 18031 IoT cybersecurity standard.
