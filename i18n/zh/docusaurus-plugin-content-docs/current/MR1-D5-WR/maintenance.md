# 维护与故障处理

## 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 电源灯不亮 | 由专业人员检查供电、电压范围及接线。检查接线前先断电并验明无电，不得打开外壳自行维修。 |
| Wi-Fi 无法连接 | 确认 2.4 GHz Wi-Fi 覆盖、网络名称和密码，并检查手机权限、蓝牙及设备序列号（SN）。 |
| 网络灯慢闪，但没有云端数据 | 设备可能已连路由器或已获取 IP，但尚未连接云平台。检查网络能否访问外网、账号绑定状态及数据时间。 |
| 电流为零或偏差较大 | 断电后，检查 CT 是否闭合、插头是否连接、CT 是否套在单根导线上，以及 100 A 或 400 A 料号是否匹配。 |
| 功率方向有误或三相数据异常 | 结合实际发电、用电工况判断。断电后核对 CT 方向，以及 L1、L2、L3 与各 CT 的相别对应关系。 |
| LoRa 无法连接 | 确认使用 WR 型号和兼容的 868 MHz 系统，并检查配套设备状态与固件配置。W 型号不支持 LoRa。 |
| 数据更新比预期慢 | 区分内部刷新、采集和上传间隔，检查数据时间及上传配置。 |
| 升级后未恢复在线 | 记录指示灯状态和固件版本，确认网络及供电，并联系服务人员。 |

指示灯状态见[外观、接口与指示灯](overview/appearance.md#指示灯)，规格与上传间隔见[参数对比](parameter-comparison.md)。

## 日常维护

- 定期检查外壳、导轨固定件、端子、CT 锁扣和线束，并查看数据是否连续。清洁和电气维护前先断电。
- 更换电表或 CT 时确认料号匹配，更换后重新验证通电和计量。
- 损坏的设备应停止使用。请排查故障原因，避免反复复位。
- 联系服务人员时，请提供型号、料号、SN、CT 规格、固件版本、故障发生时间、指示灯状态及接线照片。服务入口见[联系信息](contact.md)。
