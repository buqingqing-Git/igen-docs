# 前言

## 概述

本手册介绍 D5 系列电表的功能、安装与调测、数据平台、技术指标及维护和故障处理,使用设备前请仔细阅读本手册。

本手册适用于 MR1-D5-W、MR1-D5-WR、MR3-D5-W 和 MR3-D5-WR 四种型号。型号命名与区别见[型号说明](overview/model-description.md)。

:::info 信息
设备迭代或其他原因可能导致手册更新。请以所购产品实物为准，并通过官方或销售渠道获取最新资料。手册图片仅供参考，除非另有约定，本手册仅作使用指导，其中的陈述、信息和建议不构成任何明示或暗示的担保。有关使用与版权的说明见[声明](safety/disclaimer.md)。
:::

## 读者对象

本手册适用于负责 D5 系列电表安装、操作和维护的专业技术人员，以及使用设备的用户。电气安装必须由符合[安全注意事项](safety/safety-instructions.md)要求的专业人员执行。
