# 型号说明

本手册覆盖单相型号 **MR1-D5-W、MR1-D5-WR** 和三相型号 **MR3-D5-W、MR3-D5-WR**。W 和 WR 型号均支持 Wi-Fi；其中 WR 型号还支持 LoRa。

<img src={require('./img/model-breakdown.png').default} alt="MR1-D5-WR 型号拆解" width="300" />

| 序号 | 含义 | 取值 |
| --- | --- | --- |
| ⑴ | 产品标识 | MR：多功能电能表。 |
| ⑵ | 相数 | 1：单相；3：三相。 |
| ⑶ | 产品代际 | D5：第 5 代产品。 |
| ⑷ | 通信方式 | W：支持 Wi-Fi；R：支持 LoRa。 |

各型号的详细差异见[参数对比](../parameter-comparison.md)。
